# LifeSaver – Blood Donor Management Platform

## Project Overview

LifeSaver is a cloud-based blood donor management platform designed to help users find suitable blood donors efficiently.

The project aims to demonstrate the design and implementation of a secure, scalable three-tier application using cloud computing and DevOps practices.

## Project Goals

- Develop a responsive frontend.
- Build REST APIs using Python Flask.
- Store application data in MySQL.
- Deploy the application using AWS services.
- Containerize the backend using Docker.
- Automate build and deployment using Jenkins.
- Provision cloud infrastructure using Terraform.
- Implement monitoring, security, and CI/CD practices.

## Planned Architecture

1. Presentation Tier – Frontend
2. Application Tier – Flask REST API
3. Database Tier – MySQL on Amazon RDS

## Technology Stack

- Python and Flask
- HTML, CSS and JavaScript
- MySQL
- AWS
- Docker
- Jenkins
- Terraform
- Git and GitHub
